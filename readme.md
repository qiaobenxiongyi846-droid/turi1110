# 海釣り

ブラウザで遊べる、シンプルな釣りゲームです。深く投げるほど大きな魚がいますが、引き上げるのは難しくなります。全5投の合計スコアを伸ばしましょう。

## 遊ぶ

`game/umitsuri.html` をブラウザで開くだけで遊べます。インストールや通信は不要です。
紹介ページは `index.html` です。

## 遊び方

1. 画面をクリックして、投げる準備をする
2. ゲージが動くので、狙う深さ（右ほど深い）でクリックして投げる
3. 魚がヒットしたら、ゲージの緑のゾーンでクリックして引き上げる
4. 全5投で合計スコアを競う

BGMのオン／オフは画面上のボタン、または `M` キーで切り替えられます。

## スコア

| サイズ | 深さ | 得点 |
| --- | --- | --- |
| 小 | 浅い | 5点 |
| 中 | 中くらい | 10点 |
| 大 | 深い | 15点 |
| 黄金の魚 | 深場（まれに出現） | 100点 |

合計点によるランク：20点〜 釣り人見習い / 40点〜 釣り上手 / 60点〜 釣り名人 / 黄金の魚を釣ると「伝説の釣り人」

## 特徴

- 浅い・中間・深いの各30種、合計90種に、幻の黄金の魚3種を加えた全93種
- 釣った魚を記録する図鑑（カードをクリックすると説明を表示）
- 図鑑の記録は端末のブラウザ（localStorage）にのみ保存され、外部には送信されません
